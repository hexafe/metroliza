# Group Analysis Guide

This folder contains the end-user guide for exported **Group Analysis** output.
The active reading surface is the exported HTML dashboard, especially the **Group comparison**
section, metric jump list, key takeaways, metric blocks, plots, run notes, and detailed tables.

Files in this folder:

- [user_manual.md](user_manual.md) - the main dashboard-first manual.
- [user_manual.pdf](user_manual.pdf) - the printable PDF companion.

If you need help setting up Export grouping, start with [../export_grouping.md](../export_grouping.md).
If you need help using the Export dialog itself, start with [../export_overview.md](../export_overview.md).
