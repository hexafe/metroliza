E10 commands (PowerShell, while the app is running; repeat the capture during OCR and export).
Set `$csv` to a new file name for each exit you test (for example `-menu`, `-close`):

```powershell
$exe = 'metroliza_2026.09rc1_261031_launcher.exe'
$csv = Join-Path ([Environment]::GetFolderPath('Desktop')) 'metroliza-261031-pids-menu.csv'
function Get-Tree([uint32]$id) {
  Get-CimInstance Win32_Process -Filter "ParentProcessId=$id" | ForEach-Object { $_; Get-Tree $_.ProcessId }
}
$root = @(Get-CimInstance Win32_Process -Filter "Name='$exe'")
if ($root.Count -ne 1) { throw "Expected one running $exe, found $($root.Count)" }
@($root) + @(Get-Tree $root[0].ProcessId) |
  Select-Object ProcessId, ParentProcessId, Name, @{n='Created';e={$_.CreationDate.ToString('o')}} |
  Export-Csv -Append -NoTypeInformation $csv
```

After quitting, wait 10 seconds and run:

```powershell
Import-Csv $csv | Sort-Object ProcessId -Unique | ForEach-Object {
  $p = Get-CimInstance Win32_Process -Filter "ProcessId=$($_.ProcessId)"
  if ($p -and $p.CreationDate.ToString('o') -eq $_.Created) { "LEFT: $($p.ProcessId) $($p.Name)" }
}
Get-Process metroliza* -ErrorAction SilentlyContinue | Select-Object Id, ProcessName, StartTime
```

No `LEFT:` line means PASS. The creation time guards against a reused PID. The last command is a
supplementary sweep for a worker started after your last capture: record anything it lists and
check whether it belongs to this instance (start time) or to another program or copy.

While running E3, E9 and E10, write down any delay at exit, error dialog or leftover process. Those
observations feed #1184; do not run extra series without a named risk.

## Scope of the existing drivers

`scripts/qualify_windows_candidate_core.py` runs on the onedir only. The launcher EXE carries
that same onedir (content hash above), but packing does not by itself accept the launcher start
path. `scripts/qualify_windows_portable_onefile.py --kind launcher` covers only cold first launch,
verified reopen, hard exit and preview on the EXE, plus the runtime cache layout. No existing
driver runs import, OCR, filter, group, export or Excel locking on the EXE, so E1–E12 stay manual.
